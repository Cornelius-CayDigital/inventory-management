Factory Inventory Management

System architecture, tech stack and data flow. A Vue 3 single-page app talks to a FastAPI service over REST; all data is loaded from JSON files into memory at startup. There is no database.

Request data flow

  1. User changes a filter in FilterBar; it writes to the shared refs in useFilters.
  2. The active view watches those refs and calls getCurrentFilters() → { warehouse, category, status, month }.
  3. api.js builds query params (skipping all) and issues GET /api/… with axios.
  4. FastAPI runs apply_filters / filter_by_month over the in-memory lists from mock_data.py.
  5. Responses are validated against Pydantic response_models and returned as JSON.
  6. The view stores raw data in refs; KPIs, tables and charts are derived in computed properties.
